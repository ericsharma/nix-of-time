## The three runtime tiers

Every service lands in exactly one tier, chosen by what it actually needs — not
by preference.

## Two rules that cause most of the pain

**A new `.nix` file must be `git add`ed before a rebuild.** The flake sees only
tracked files. An untracked module is skipped in silence — the closure barely
changes and the units never appear.

**trigkey globs all of `hosts/nixos/optional/`.** Those modules carry no enable
flags and several assume trigkey's hardware. Never copy that import block to
another host; list imports one by one, as `gmktec` does.
